# Qwen3-4B PromptCraft

Fine-tuned Qwen3-4B model for Zero-Reasoning System Prompt Engineering.

## Hugging Face Repository
Find the quantized GGUF weights here: [https://huggingface.co/Sandeep4235/Qwen3-4B-PromptCraft-GGUF](https://huggingface.co/Sandeep4235/Qwen3-4B-PromptCraft-GGUF)

## Project Overview
This repository contains the training pipeline used to fine-tune Qwen3-4B on 2,050+ structured instruction pairs to generate production-grade system prompts without internal reasoning leaks.
